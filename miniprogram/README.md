# 硕方 T50 微信小程序编辑器

这是一个从空白架构重建的微信小程序标签编辑器。小程序业务层不依赖旧页面实现，只使用仓库中已验证的 `LabelDocument` 数据边界和 T50 BLE 打印协议。

## 主要交互

- 首页可新建空白标签、复制模板、继续草稿或从系统剪贴板导入可编辑标签。
- 编辑页使用微信 Canvas 2D。直接点选对象后可拖动，拖右下角控制点可缩放，双击可编辑内容。
- 画布下方固定六个按键：微调模式、左、上、下、右和顺时针旋转 90°。微调模式在关闭、1 mm、0.1 mm 之间循环。
- 底部工具栏提供添加、属性、复制、删除、模板和打印。
- 图片在本机转换为 1-bit 黑白点位并存入标签文档，不需要后端。
- 屏幕预览与打印点阵使用同一个渲染器，统一文字、二维码、条码和图片的尺寸与排版。

## 构建与运行

在仓库根目录运行：

```bash
npm install
npm run build:miniprogram
npm run test:miniprogram
```

随后使用微信开发者工具导入本目录的 `project.config.json`：

```text
miniprogram/project.config.json
```

`npm run build:miniprogram` 会把共享 SDK 中的 BLE 打印协议、可编辑标签剪贴板编解码器和二维码生成器打包到 `vendor/t50-core.js`。小程序本身不需要执行“构建 npm”。

蓝牙扫描和打印必须使用真机，并授予微信蓝牙及附近设备/定位权限。模拟器可以验证页面、画布编辑、模板、草稿和剪贴板导入，但不能验证真实出纸。

## 数据与隐私

草稿保存在微信本地存储。图片只保留阈值化后的黑白点位；标签内容、图片和打印任务不会上传到服务器。
