# 全新 LabelDocument 小程序 MVP

这是独立重建的小程序入口，不复用旧小程序的页面、画布或打印业务。

请在微信开发者工具中直接导入本目录（`miniprogram/project.config.json`），不要导入仓库根目录。

当前流程：

1. 浏览器编辑器点击“复制到小程序”。
2. 小程序首页点击“从剪贴板导入”。
3. 读取 `SUPVAN1:<base64url-json>`，恢复 `LabelDocument`。
4. 直接点击 Canvas 预览中的元素进行选择，再修改变量、文字、二维码、条码内容，以及允许编辑的 X/Y/宽/高等属性。
5. 可以在编辑页直接添加文字、二维码、条码、矩形和直线；新元素会自动选中，方便继续编辑。
6. 画布下方只保留六个紧凑控制键：开启/关闭 0.1 mm 微调、上下左右四向移动，以及 90° 旋转；Canvas 只读预览，保持毫米坐标和 8 dots/mm 的标签映射。

二维码预览使用真实 QR 矩阵，并按标签对象的完整宽高绘制，与浏览器编辑器保持同样的尺寸映射。

剪贴板解析和文档校验位于 `domain/transfer.js`，不依赖 DOM、SVG 或浏览器 API。打印能力可以在这个新结构上继续增加，但当前小程序明确不包含旧打印业务。
