# 硕方 T50 浏览器标签编辑器

这是一个用于制作和打印 T50 标签的浏览器编辑器。它提供可视化画布、多页文档、对象编辑和设备状态查看，完成编辑后通过 Web Bluetooth 或 WebHID 连接打印机。

## 启动

需要 Node.js `>=20.19`。在项目根目录执行：

```bash
npm install
npm run dev
```

## 编辑标签

编辑器预置 `30 × 20`、`40 × 30`、`50 × 30`、`50 × 40`、`40 × 60`、`50 × 70`、`50 × 80` mm，也支持宽 `5-50` mm、高 `5-120` mm 的自定义尺寸。

页面可以添加文字、条码、二维码、图片、矩形和直线。你可以新增、复制、切换和删除页面，也可以对对象进行多选拖动、吸附、对齐、分布、图层调整、撤销重做和键盘微调。

工具栏中的模板按钮提供预制标签。选择模板后会复制出一份新的 `LabelDocument`，可以继续修改文字、码内容和对象位置；模板本身不会被覆盖。模板中的图片会先转为热敏黑白图，项目数据只保留压缩后的 1-bit 点位。

点击“复制到小程序”会把可编辑标签数据写入系统文本剪贴板，格式为 `SUPVAN1:<base64url-json>`。小程序端使用 `wx.getClipboardData` 读取后，校验并解析 `LabelTransferPackage.document`，即可恢复文字、条码、二维码、图片点位和尺寸；这不是 PNG 图片粘贴。

工具栏中的“从剪贴板导入标签”也使用同一协议，可以把小程序或其他网页端复制出的 `SUPVAN1` 数据重新载入浏览器画布继续编辑。浏览器需要在 HTTPS 或 localhost 下，并由用户点击按钮触发剪贴板读取权限。

编辑器支持以 `width="40mm" height="30mm" viewBox="0 0 40 30"` 为约定导出 SVG，也可以导入内嵌图片的安全 SVG 子集。SVG 是交换格式，打印前仍会转换为 T50 黑白点阵。

## 连接并打印

连接设备时可选 Web Bluetooth 或 WebHID。设备选择必须由用户操作触发，并运行在 HTTPS 或 localhost 环境中。

点击打印后，编辑器会按标签尺寸和 T50 点密度生成每页的 RGBA 图像，并在导出时按热敏阈值转换为黑白点阵，再交给打印 SDK。T50 不支持连续灰度打印；编辑区缩放只影响预览，不会改变发送给打印机的点数。打印前会读取设备状态，盖子、耗材、忙碌或连接异常时不会发送打印任务；状态栏中的设备状态可以手动刷新。

## 验证

```bash
npm run typecheck
npm run test
npm run build
```

这些命令会检查整个项目的类型、测试和生产构建。设备权限、真实蓝牙连接和出纸效果需要在支持相应 API 的浏览器和打印机上验证。
