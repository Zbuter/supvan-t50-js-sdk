# 硕方 T50 浏览器标签编辑器

这是一个用于制作和打印 T50 标签的浏览器编辑器。它提供可视化画布、多页文档和打印设置，完成编辑后直接通过 Web Bluetooth 或 WebHID 连接打印机。

## 启动

需要 Node.js `>=20.19`。在项目根目录执行：

```bash
npm install
npm run dev
```

## 编辑标签

编辑器预置 `30 × 20`、`40 × 30`、`50 × 30`、`50 × 40`、`40 × 60`、`50 × 70`、`50 × 80` mm，也支持宽 `5-50` mm、高 `5-120` mm 的自定义尺寸。

页面可以添加文字、条码、二维码、图片、矩形和直线。你可以新增、复制、切换和删除页面，也可以对对象进行多选拖动、吸附、对齐、分布、图层调整、撤销重做和键盘微调。

## 连接并打印

连接设备时可选 Web Bluetooth 或 WebHID。设备选择必须由用户操作触发，并运行在 HTTPS 或 localhost 环境中。

点击打印后，编辑器会按标签尺寸和 T50 点密度生成每页的 RGBA 图像，并在导出时按热敏阈值转换为黑白点阵，再交给打印 SDK。T50 不支持连续灰度打印；编辑区缩放只影响预览，不会改变发送给打印机的点数。打印对话框可以设置浓度、间隙、速度和副本数。

## 验证

```bash
npm run typecheck
npm run test
npm run build
```

这些命令会检查整个项目的类型、测试和生产构建。设备权限、真实蓝牙连接和出纸效果需要在支持相应 API 的浏览器和打印机上验证。
